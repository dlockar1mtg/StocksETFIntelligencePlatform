# Phase 0.1 — Governance Authority Package

## Objective

Convert the approved governance decisions from UniversalInvestmentPlatform
Issue #32 into repository-controlled, human-readable, and machine-readable
authority artifacts.

## In Scope

- Platform charter
- Authority boundaries
- Decision register
- Prohibited actions
- Certification authority matrix
- Repository architecture standard
- Implementation roadmap
- Governance manifest
- Governance validation tests

## Out of Scope

Phase 0.1 does not include:

- Live market-data collection
- ETF analytics
- Return calculations
- Forecasting
- Ranking
- Purchase recommendations
- Contribution allocation
- UIP production export
- Individual-stock analysis
- Automatic execution

## Acceptance Criteria

Phase 0.1 is complete when:

1. All 16 approved decisions are represented in the repository.
2. The governing UIP issue is identified.
3. The platform and UIP authority boundaries are documented.
4. Prohibited actions are machine-verifiable.
5. Initial ETF scope is VOO, SCHD, and QQQM.
6. Automatic execution is explicitly false.
7. Direct UIP database writes are explicitly false.
8. Governance JSON is valid and testable.
9. Automated governance tests pass.
10. The work is committed on the Phase 0.1 branch.
