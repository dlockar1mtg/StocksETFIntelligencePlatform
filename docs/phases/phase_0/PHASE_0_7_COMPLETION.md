# Phase 0.7 — Integrated Foundation Certification

## Purpose

Phase 0.7 certifies the complete Phase 0 foundation as one governed system. It verifies that governance, repository architecture, contracts, source authority, data zones, security identity, ETF universe eligibility, market calendars, return standards, and corporate-action controls remain mutually consistent and fail closed.

## Included subphases

- Phase 0.1 — Governance authority
- Phase 0.2 — Repository foundation
- Phase 0.3 — Contracts and configuration
- Phase 0.4 — Source authority and data zones
- Phase 0.5 — Security master and ETF universe
- Phase 0.6 — Calendar, return, and corporate-action standards
- Phase 0.7 — Integrated foundation certification

## Acceptance criteria

- all required governed control files exist and parse
- all Phase 0.1 through 0.7 regression tests execute
- at least 56 tests run successfully
- Tier 1 security identity is consistent across the security master and universe policy
- all benchmark references resolve
- market calendar authority remains Tier 1
- return comparisons remain total-return based
- unknown sources remain blocked
- source conflicts remain preserved
- production authority remains disabled
- automatic execution remains disabled
- direct UIP production database writes remain disabled
- individual-stock production remains disabled

## Authorized scope

Phase 0 completion authorizes foundation development, governance validation, contract validation, source-governance validation, security-master validation, market-standard validation, and research-only development.

## Explicitly unauthorized

Phase 0 completion does not authorize certified market monitoring, certified asset outlooks, portfolio actions, contribution allocations, UIP exports, direct UIP production database writes, or automatic execution.

## Next phase

Phase 1 may begin only from a passing Phase 0 integration certification and must introduce operational ingestion and monitoring capabilities without weakening any Phase 0 authority boundary.
